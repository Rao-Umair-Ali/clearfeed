ClearFeed Privacy Policy

Last updated: May 2026
ClearFeed is built with a privacy-first approach. It does not collect, store, or transmit any personal user data to external servers.

1. Overview

ClearFeed is a Chrome extension designed to improve digital wellbeing by reducing addictive scrolling on YouTube, Instagram, and TikTok. It removes distracting interface elements and helps users browse intentionally.

2. Data Collection

ClearFeed does NOT collect any personal user data.

  • Personally identifiable information
  • Passwords or authentication data
  • Financial or payment information
  • Web browsing history outside extension functionality
  • Location data
  • Messages or communications

3. Local Data Storage

All settings and usage statistics are stored locally on the user's device using Chrome storage APIs.

  • Platform preferences (YouTube, Instagram, TikTok)
  • Exam Mode settings
  • Focus session timers
  • Streak and usage statistics

4. Permissions Usage

  • Storage: Save user preferences locally
  • Scripting: Modify supported websites
  • Tabs: Detect navigation changes
  • Alarms: Manage timers and focus sessions
  • Notifications: Show focus alerts
  • Host permissions: Apply UI modifications
  • DeclarativeNetRequest: Optional Exam Mode blocking

5. Website Interaction

ClearFeed modifies the visual layout of YouTube, Instagram, and TikTok locally in the browser. No data is sent to external servers.

6. Data Sharing

  • No data is sold
  • No data is transferred to third parties
  • No analytics or tracking services are used

7. Security

All data remains on the user's device or Chrome Sync storage. No external databases are used.

8. Children’s Privacy

ClearFeed does not knowingly collect any data from users, including children.

9. Changes

This policy may be updated in future versions. Updates will be published on this page.
