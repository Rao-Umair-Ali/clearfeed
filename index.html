ClearFeed Privacy Policy Last updated: May 2026 1. Overview ClearFeed is a Chrome extension designed to improve digital wellbeing by reducing addictive scrolling on supported websites such as YouTube, Instagram, and TikTok. It removes distracting interface elements and helps users browse intentionally. This Privacy Policy explains what data is (and is not) collected, stored, and processed. --- 2. Data Collection ClearFeed does NOT collect, transmit, sell, or share any personal user data to external servers. We do NOT collect: - Personally identifiable information (name, email, address) - Passwords or authentication data - Financial or payment information - Web browsing history outside the extension’s functionality - Location data - Messages or personal communications --- 3. Data Stored Locally All user settings and usage data are stored locally on the user’s device using Chrome storage APIs. This may include: - User preferences (enabled/disabled platform filters) - Exam Mode settings - Focus session timers - Streak count and usage statistics (e.g., time reclaimed) - Feature toggles for YouTube, Instagram, and TikTok This data remains on the user’s device and is never transmitted to external servers. --- 4. Permissions Usage ClearFeed uses Chrome extension permissions solely for its core functionality: - Storage: Save user settings and local statistics - Scripting: Modify page content on supported sites - Tabs: Detect navigation and apply filters - Alarms: Manage timers, streak updates, and focus sessions - Notifications: Provide focus and session alerts - Host permissions: Apply UI modifications to supported websites - DeclarativeNetRequest: Optional blocking during Exam Mode sessions No permission is used for tracking or profiling users. --- 5. Website Interaction ClearFeed modifies the visual layout of: - YouTube - Instagram - TikTok This is done locally in the browser to remove distracting elements such as feeds, recommendations, Shorts, and Reels. No page content is sent to external servers. --- 6. Data Sharing We do NOT: - Sell user data - Transfer user data to third parties - Use data for advertising or profiling - Share data with analytics services --- 7. Security Since all data is stored locally in the browser, security depends on the user’s device and Chrome’s built-in security mechanisms. ClearFeed does not maintain external databases or servers. --- 8. Children’s Privacy ClearFeed does not knowingly collect any data from children or any users. --- 9. Changes to This Policy This Privacy Policy may be updated in future versions of the extension. Updates will be reflected in the GitHub Pages link or official hosting location. --- 10. Contact If you have questions or support requests, contact: - Support Page: https://your-support-url.com - Or GitHub Issues (if applicable) --- End of Privacy Policy
